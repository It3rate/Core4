### Core4 Experimental Bootstrap Note (Revised)

This note captures a newer bootstrap picture for the experimental relation model. It is intentionally separate from earlier notes to sharpen meanings aggressively, specifically focusing on the physical constraint that **fully partitioned structures cannot legally add together through structural merging**. The goal is to state the smallest physical picture capable of generating basis, value, operation, fold, power, and orientation from one shared ordered integration substrate.

#### 1. Bootstrap Stance
Before anything is related or committed, a carrier presents a field of long-valued potentials. Nothing deeper than ordered potential is assumed yet. The first primitive act is to choose one potential as A, choose another as B, and relate A -> B in that order. This ordered relation is the bootstrap act.

#### 2. Ordered Extent And Tick Matter
Relating A -> B creates a directed extent. This does not require pinning either endpoint to a globally fixed substrate location; the relation may slide on the substrate while remaining perfectly lawful internally. This means later structures can be stable internally while moving relative to the wider substrate.

At bootstrap grade, the distance between raw values determines the structural partition count. If A != B, interior tick matter exists; if A < B, it is dominant/expansive; if A > B, it is recessive/inverted; if A = B, no interior tick matter is created. This means extent and raw partition count coincide physically at this earliest grade.

#### 3. Open Site, Point Claim, And Calibrated Basis
The cleanest current bootstrap ladder uses three importantly different cases:
*   **0/0**: Open site or unresolved coincidence. It does not claim a usable magnitude.
*   **m/0**: Point claim. It has a committed magnitude present, but its interior tick matter, flow orientation, or support structure is not yet disclosed. It is present in magnitude without disclosed interior partitions.
*   **m/u**: Resolved value through a known basis. The magnitude is present, the basis is present, and the value can be read through the basis partitions and orientation.

#### 4. Grade 0 And Grade 1
Ordered raw relation gives the seed basis. For example, 4/0 is a point claim of magnitude 4, while 4/4 is a unit in the dominant orientation with four structural partitions. These project to values (e.g., 8/4 projects to value 2), but projected values are not the structure itself. The structure 8/4 is an extent 8 resolved through partition basis 4, and this distinction matters because structural partition count must remain available for later fusion.

#### 5. Orientation
An inverted basis is the same basis with an inverted orientation, not a separate species. A dominant basis traverses expansively, while a recessive basis traverses in the inverted direction.

An i-oriented basis should be read as operating through inverted orientation, inverting the current resolved structure as it is taken up. In repeated fold (like 2i * 3i), each new inverted participation acts on the whole currently resolved host, flipping both placement and denominator perspective in sequence.

#### 6. Higher Grade Partitioning
Partitions scale upward into higher grades. **If one resolved structure is fused with another, the higher-grade structure inherits the partition availability of its ingredients**. Fusing an 8/4 vertical structure with an 8/4 horizontal structure results in a squared unit carrying the product of those partition opportunities.

#### 7. Operations Are Relations Read As Integration
There is no separate primitive for "operation". Operations (addition, multiplication, fusion) are different uses of the same ordered relation substrate, read as integration rules. An operation dictates how to integrate operands using a specific number of partitions, repeated a specific number of times.

#### 8. Operation Core: Partitions And Repeats
The operation core consists of partitions and repeats.
*   **Repeats** specify how many times the integration acts (1 = one pass, >1 = power-like, fractional = root-like).
*   **Partitions** specify how the integration is exposed. The system uses a precedence rule to determine partitions: explicit operation partitions, then reused basis partitions, then raw tick fallback.

#### 9. The Merging Constraint: Addition vs. Multiplication
Because fusing resolved structures forces their partitions to merge and scale (multiplying the partition opportunities), **two fully partitioned structures cannot physically merge without the operation becoming a multiplication**. If internal units are allowed to merge to normalize total ticks, a scaling occurs.

Therefore, true addition requires that we **only add the numerators (magnitudes) while strictly preventing the structural denominators from interacting**.

#### 10. Addition As Zero-Mixing Integration (The Override)
To accomplish addition without illegal structural merging, the system applies a denominator of 0 directly to the operation. This acts as an explicit override.

An operation with zero partitions means: **append whole resolved values, but do not mix interiors during the operation itself**.
*   It functions as a structural safeguard that tells the system to accumulate the claims (the raw ticks or numerators) while preserving their lack of fused interior.
*   It relates separate members into one collection-like result without fusing them into one continuous extent.

By keeping the 0 on the operation rather than stripping the operands down to m/0 point claims, the operands get to keep their structural identities (m/u) intact, safely appending their magnitudes without cross-multiplying their bases.

#### 11. Multiplication As Basis Substitution
When interior mixing *is* legally allowed, the operation acts as multiplication. Multiplication-like behavior is defined as basis substitution: taking every unit proportion of the first operand and replacing or filling it with the whole of the second operand.
*   The first operand provides the host basis.
*   The second operand provides the inserted structure.
*   This fusion is done at the tick level, resulting in the shared interior and scaled partition availability expected when structures genuinely merge.

#### 12. Linked Fold Versus Snapshot Fold
Fold always produces a new output stage, which can be a one-shot snapshot or a linked result. In a link calculation, the fold relation is preserved, and later changes to reused input can retune the output.

#### 13. Structural Equality Versus Projected Equality
Two constructions may project to the same visible value while remaining different structures. For example, 6 * 2 and 2 * 6 project to the same scalar but differ structurally in host basis, inserted structure, and aspect. Projection equality must not erase construction lineage.

#### 14. What Still Feels Open
*   **Repeat Semantics:** The exact meaning of rational repeats, compression optimizations, and root alignments need tightening.
*   **Point, Carrier, And Flow:** Does an m/0 point commit to a carrier family while withholding orientation, or is it looser?
*   **Selection and Reuse Windows:** Mechanisms for sliding windows, recurrence, and trolley movement across preserved structures likely require one more layer above this bootstrap encoding.

#### 15. Current Working Summary
*   Carriers present ordered potentials; relation A -> B creates extent.
*   m/0 is present magnitude with unresolved interior flow; m/u is resolved magnitude through a known basis.
*   **Fully partitioned structures cannot legally add by merging, as merging scales partitions (multiplication)**.
*   **Addition (0-partition operation) safely appends magnitudes while actively blocking interior mixing**.
*   Multiplication is basis substitution or filled host integration.
*   Fold always produces new output, but reuse can keep it linked.
